Implementation Plan (Пошаговый план разработки)
Этап 1: Инициализация проекта и настройка ядра
•	Генерация проекта во Flutter.
•	Настройка структуры папок по фичам (Feature-first architecture): core (темы, константы, утилиты), features/home, features/menu, features/cart, features/profile.
•	Интеграция SVG-ассетов (тотемы) и локальных шрифтов Museo Sans. 
•	Создание AppTheme: настройка ThemeData с использованием цветов из спецификации (фон #3D3A38, тексты #F2EDE4) и радиусов скругления (12-16px для карточек). 
•	Выбор и подключение стейт-менеджмента (рекомендую Riverpod для чистой работы с dependency injection и мок-репозиториями).
Этап 2: Слой данных (Заглушки / Mocks)
•	Создание моделей данных: Dish (название, цена, КБЖУ, теги, список комментариев, URL видео/гифки), Event, CartItem.
•	Создание репозиториев с фиктивными данными, отражающими структуру блюд и логику из v1.html (например, "Сезонный салат", стейки, вино с учетом тегов "острое", "вегетарианское"). 
Этап 3: Базовая навигация и Инициация (Приветственный экран)
•	Разработка Splash / Welcome Screen с анимацией звезды и логотипа. 
•	Разработка MainScreen с кастомным BottomNavigationBar, использующим SVG-тотемы для вкладок: Главная, Меню, Корзина, Профиль. 
Этап 4: Разработка экрана "Главная"
•	Верстка шапки с логотипом Piligrim. 
•	Реализация горизонтального ListView.builder для блока "Сезонное".
•	Реализация горизонтального ListView.builder для "Сегодня в Пиллигрим".
•	Создание сетки (Grid) кнопок управления официантом. Добавление логики: по нажатию показывается локальный SnackBar (или кастомный Toast в стилистике бренда) "Запрос отправлен", через Future.delayed(Duration(seconds: 2)) показывается "Официант в пути".
Этап 5: Разработка экрана "Меню" (TikTok-стиль)
•	Настройка PageView.builder с вертикальным скроллом.
•	Создание виджета TikTokDishCard. Интеграция пакета video_player для зацикленного видео.
•	Наложение UI поверх медиа: название, цена, КБЖУ, теги. 
•	Блок кнопок действий справа: лайк (добавление в избранное через стейт-менеджер), комментарии (открытие BottomSheet со списком заглушек-отзывов), добавление в корзину.
Этап 6: Разработка экранов "Корзина", "Избранное" и "Профиль"
•	Корзина: ListView добавленных блюд, возможность изменения количества, подсчет итоговой суммы. Кнопка "Вызвать официанта" (аналогично логике на Главной). 
•	Избранное: Сетка (Grid) сохраненных блюд.
•	Профиль: Отображение баллов, статический список настроек (Уведомления, Рекомендации) через Switch-переключатели, блок контактов.
Этап 7: Полировка и Анимации
•	Настройка плавных переходов (Hero-анимации для переходов, scale-эффекты при нажатии кнопок). 
•	Проверка всех текстов на соответствие редполитике: обращение "герой", отсутствие "сухого" корпоративного тона

lib/
├── core/                        # Ядро приложения (всё, что используется везде)
│   ├── theme.dart               # Палитра (Қара жер, Мөлдір су и т.д.) и шрифты (Museo Sans)
│   └── constants.dart           # Пути к SVG-тотемам, локальным видео и заглушкам
├── data/                        # Слой данных (High Agency подход к бэкенду)
│   ├── models/                  # Классы данных: Dish, Event, CartItem
│   └── repositories/            # Mock-репозитории (позже просто заменим на Django REST API)
├── features/                    # Разделение по экранам и логике
│   ├── splash/                  # Приветственное окно (Инициация)
│   │   └── splash_screen.dart   
│   ├── navigation/              # Кастомный BottomNavigationBar
│   │   └── main_screen.dart     # Скелет с переключением 4-х вкладок
│   ├── home/                    # Главная
│   │   ├── home_screen.dart
│   │   └── widgets/             # Блоки "Сезонное", кнопки "Позвать официанта"
│   ├── menu/                    # Меню (TikTok-формат)
│   │   ├── menu_screen.dart
│   │   ├── menu_provider.dart   # Riverpod-состояние для управления видео
│   │   └── widgets/             # Карточка блюда с видео/гифкой
│   ├── cart/                    # Корзина
│   │   ├── cart_screen.dart
│   │   └── cart_provider.dart   # Логика добавления, подсчета суммы и баллов
│   └── profile/                 # Профиль и Избранное
│       └── profile_screen.dart
└── main.dart                    # Точка входа, оборачиваем в ProviderScope (Riverpod)
